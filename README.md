# Lukas

Tu llave pa' la plata. Una app de finanzas personales hecha a la medida, que se instala en el iPhone desde Safari y funciona sin internet.

- Todos los datos se quedan en el teléfono (localStorage). Este repositorio solo contiene el código.
- Para instalarla: abre la página en Safari › Compartir › **Agregar a inicio**.
- Para publicar un cambio: sube `VERSION` en `sw.js` para que el iPhone descargue la versión nueva.

Hecha con HTML, CSS y JavaScript, sin dependencias ni paso de compilación.
